## 📊 项目概述

本项目基于银行信用卡客户数据集，通过完整的数据分析流程，深入挖掘用户行为模式，识别关键业务风险与增长机会。项目展示了从数据清洗到业务洞察的全流程分析能力，为银行客户关系管理、风险控制和产品优化提供了数据支持。

## 🎯 项目目标

- **客户分群：** 识别不同价值层次的客户群体
- **流失分析：** 定位高流失风险客户特征
- **产品诊断：** 分析现有信用卡产品结构问题
- **业务建议：** 基于数据洞察提出可落地的优化策略

## 🛠️ 技术栈

- **编程语言:** Python 3.8+
- **数据分析:** Pandas, NumPy
- **数据可视化:** Plotly, Matplotlib
- **开发环境:** Google Colab / Jupyter Notebook
